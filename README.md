# Web App for Contacts

Веб-приложение -- телефонная книга

## Установка

1. Установи зависимости:
pip install -r requirements.txt

2. Создай .env по .env.example

3. Перед первым запуском запусти:
python dbcontacts.py

4. Запусти: 
python web.py

## Функции

- Просмотр контактов
- Поиск по имени
- Добавление контактов
- Удаление контактов

## Стек

- Python 3.14
- Flask
- PostgreSQL
- psycopg2
- Jinja2
- HTML/CSS
- Git
